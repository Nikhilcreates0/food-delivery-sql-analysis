# 🍔 Food Delivery Data Analysis | MySQL

An end-to-end SQL analysis project exploring food delivery operations, restaurant performance, revenue trends, customer behavior, and delivery efficiency using MySQL.

## 📌 Project Overview

This project focuses on analyzing food delivery data using MySQL to uncover meaningful business insights and understand operational performance.

SQL queries are used to examine order patterns, revenue distribution, customer purchasing behavior, restaurant performance, discounts, and delivery operations.

## 🎯 Business Objectives

- Analyze overall order volume and revenue.
- Identify top-performing restaurants.
- Understand peak ordering hours and days.
- Examine order cancellation and rejection patterns.
- Analyze customer retention and repeat purchases.
- Evaluate restaurant ratings and customer satisfaction.
- Investigate delivery efficiency and operational performance.
- Understand the impact of discounts on restaurant sales.

## 🛠️ Tools & Technologies

- **Database:** MySQL
- **Language:** SQL
- **Concepts:** Aggregations, Joins (where applicable), Subqueries, Window Functions, CASE Statements, Date & Time Functions, GROUP BY, ORDER BY, and Filtering.

## 📊 Analysis & Business Questions

The SQL analysis covers the following areas:

### 1. Sales & Revenue Analysis
- What is the total number of unique orders?
- What is the total revenue from delivered orders?
- What is the average order value?
- Which restaurants generate the highest revenue?
- How does revenue change monthly?

### 2. Restaurant Performance
- Which restaurants receive the highest number of orders?
- Which restaurants generate the most revenue?
- Which restaurants have the highest average customer ratings?
- How do discounts vary across restaurants?

### 3. Customer Behavior
- Which customers place the most orders?
- How many customers are repeat customers?
- What are the ordering patterns throughout the week?

### 4. Order & Operational Analysis
- What is the distribution of order statuses?
- What is the overall cancellation and rejection rate?
- What are the most common cancellation reasons?
- What is the average kitchen preparation time?
- What is the average rider waiting time?

### 5. Time-Based Analysis
- Which hours receive the highest number of orders?
- Which days of the week have the highest order volume?
- Which hours generate the highest revenue?

### 6. Delivery Analysis
- How do orders vary across delivery methods?
- What is the relationship between delivery distance and order value?
- How many orders are successfully delivered across delivery methods?

## ⚙️ How to Run the Project

1. Install MySQL and open MySQL Workbench.
2. Import the food delivery dataset into your MySQL database.
3. Ensure the database is named `food_delivery_db`.
4. Ensure the table is named `food_delivery`.
5. Open `food_delivery_analysis.sql`.
6. Execute the queries to explore the analysis.

**Note:** The dataset is not included in this repository. You need to import the corresponding dataset separately before executing the queries.
